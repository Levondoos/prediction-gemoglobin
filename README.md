Обучение грдиентного бустинга для предсказания гемоглобина в крови по показателям из мочи

Проект посвящён обучению и оценки градиентного бустинга (XGBoost) на табличных данных с воспроизводимыми запусками через Bash-скрипт. Управление зависимостями — через uv.

Проект включает себя следующие файлы:
    src/load_dataset.py - загрузка датасета из kaggle и сохранение его в data/raw.

    src/prepare.py - предобработка загруженного датасета и разделение его на тренировочную и тестовую выборку (data/processed/train.csv и data/processed/test.csv соответственно)

    src/train.py — обучение модели XGBoost на data/processed/train.csv и сохранение в формате .joblib.

    src/evaluate.py — оценка модели на data/processed/test.csv с сохранением метрик в JSON в директорию reports/.

    run_experiment.sh — Bash-обёртка, объединяющая обучение и оценку в один воспроизводимый запуск с логированием и замером времени.

    pyproject.toml / uv.lock — описание окружения и зафиксированные версии зависимостей (pandas, scikit-learn, xgboost, kagglehub и др.).

Требования к окружению

    Python: >= 3.14.4 

    uv: актуальная версия (>= 0.12.23)

    ОС: Linux 

    Bash: >= 4.x

Установка зависимостей

Все зависимости зафиксированы в uv.lock. Установка одной командой:

    uv sync

После синхронизации запускать скрипты можно через uv run, например:

    uv run python src/train.py

Запуск

Базовый запуск эксперимента с параметрами по умолчанию:

    chmod +x run_experiment.sh
    ./run_experiment.sh

Или через uv (чтобы гарантированно использовать окружение проекта):

    uv run bash run_experiment.sh

Пример запуска с гиперпараметрами:

    ./run_experiment.sh \
      --n-estimators 500 \
      --max-depth 7 \
      --learning-rate 0.05 \
      --seed 123 \
      --model-out models/xgb_v2.joblib \
      --tag "tuned-run"


Скрипт включает в себя следующие гиперпараметры:

    Флаг	Длинный флаг	Описание
    -n	--n-estimators	Число деревьев (по умолчанию 100)
    -o	--model-out	Путь сохранения модели (по умолчанию models/model.joblib)
    -m	--max-depth	Глубина дерева (по умолчанию 5)
    -s	--seed	Random seed (по умолчанию 42)
    -l	--learning-rate	Скорость обучения (по умолчанию 0.01)
    -t	--tag	Метка запуска
    -h	--help	Показать справку и выйти
